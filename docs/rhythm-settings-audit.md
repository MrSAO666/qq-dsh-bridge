# 回复节奏与人物卡核查（2026-11-03）

## 页面与反馈

回复节奏复用 B 站页的标题区域、卡片分组、两列表单、开关与窄屏单列样式。保留原有字段；旧版轮询间隔显示为禁用，只供查看历史值。新增当前实际使用的私聊回复窗口时长。

所有设置弹窗内触发的提示均挂在弹窗内部，避免跑到悬浮球附近或被弹窗遮挡。思考强度独立保存，节奏设置统一保存。

## 人物卡注入

原逻辑：小于等于 1200 字的卡进入唤醒消息，较长卡只提示角色名并要求模型调用 `qq_get_prompt`。因此“角色已选中”并不证明长卡正文已进入模型上下文。

现在开启 `socialV2.injectViaSystemPrompt` 时：`/api/socialV2/agent-context` 按当前角色、模式过滤与字数上限生成卡片正文；`qq-agent-context` 将它注册为该会话的 `qq:session-context` 系统提示词段，普通唤醒消息不重复加入卡片正文。接口额外返回角色名、实际字符数和上限，便于管理端核查而无需输出提示词全文。

新会话创建时读取；已有会话每 120 秒刷新。启动时桥接不可用的已存在会话也会重新尝试发现和注入。更换角色或编辑卡片后，已有会话最多约两分钟更新。这里验证的是上下文装配，不能保证模型每次都完全遵守人物卡。
